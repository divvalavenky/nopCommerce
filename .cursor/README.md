# Cursor project config (nopCommerce)

Files generated by cloud-agent `/setup-pstack` and `/create-verification-skill`, checked into the repo so desktop and cloud share the same paths.

| Path | Purpose |
|------|---------|
| `rules/pstack-models.mdc` | pstack per-role model map (`alwaysApply`); budget **medium (high)** |
| `skills/verify-nopcommerce/` | Isolated storefront verification skill + `control-nopcommerce` helper |
| `skills/verify-nopcommerce/features/` | Feature map recipes |
| `skills/verify-nopcommerce/examples/proof1/` | Checked-in screenshots from the first end-to-end proof run |

Local/runtime proof dumps go under `skills/verify-nopcommerce/artifacts/` (gitignored). Re-run `/setup-pstack` or edit `rules/pstack-models.mdc` to change models.
